## MEDIUM

### 1. Path Traversal in File Operations
- **File:** `main.py` (lines 1647-1668, 1673-1703, 1733-1743, 1996-2025, 2521-2554, 2914-2938)
- **Affected functions:** `send_file`, `download_media`, `set_profile_photo`, `edit_chat_photo`, `send_voice`, `send_sticker`
- **Issue:** Multiple functions accept a `file_path` parameter from the MCP client without path sanitization or directory restriction. `send_file` checks `os.path.isfile()` and `os.access()` but these only confirm existence and readability -- they don't prevent reading arbitrary files. A prompt injection attack could exfiltrate sensitive files (e.g., `~/.ssh/id_rsa`, `.env`) by sending them to an attacker-controlled Telegram chat.
- **Fix:** Add path allowlisting:
  ```python
  import os

  ALLOWED_BASE_DIR = os.path.expanduser("~/telegram-mcp-files")

  def validate_file_path(file_path: str) -> str:
      resolved = os.path.realpath(file_path)
      if not resolved.startswith(os.path.realpath(ALLOWED_BASE_DIR)):
          raise ValueError(f"File path not within allowed directory")
      return resolved
  ```

## LOW

### 2. Tracked File Despite `.gitignore`
- **File:** `claude_desktop_config.json`
- **Issue:** File was committed in `ecb5b88` and remains tracked despite being in `.gitignore`. Currently contains only placeholder paths, but pattern risks future credential exposure if modified with real paths.
- **Fix:** `git rm --cached claude_desktop_config.json`

### 3. PII Logged in Plaintext -- Invite Hashes
- **File:** `main.py:2419,2517`
- **Issue:** `join_chat_by_link` and `import_chat_invite` log full invite hashes in error messages. Invite hashes grant access to private groups.
- **Fix:** Redact or truncate invite hashes in log messages (show only first 4 characters).

### 4. PII Logged in Plaintext -- Phone Numbers
- **File:** `main.py:1347,1350`
- **Issue:** `add_contact` logs phone numbers in exception messages.
- **Fix:** Redact phone numbers in log messages.

### 5. Non-Cryptographic PRNG for Message IDs
- **File:** `main.py:3278,3281,3298`
- **Issue:** `create_poll` uses `random.randint()` (Mersenne Twister, predictable) for `poll.id` and `random_id` values.
- **Fix:** Use `secrets.randbelow(2**63)` instead.

### 6. Bare `except:` Clause
- **File:** `main.py:1173`
- **Issue:** Bare `except:` in `get_contact_chats` catches all exceptions including `SystemExit` and `KeyboardInterrupt`.
- **Fix:** Change to `except Exception:`.

### 7. No Input Size Bounds
- **File:** `main.py` (various)
- **Issue:** Parameters like `page_size`, `limit`, `context_size` have no upper bounds. An adversarial client could request `limit=999999`, causing the server to attempt to fetch all messages into memory.
- **Fix:** Add `min()` caps: `page_size = min(page_size, 100)`, `limit = min(limit, 500)`.

### 8. Session String Exposure Risk (Informational)
- **File:** `main.py:64,68-73`
- **Issue:** The Telegram session string loaded from env vars is equivalent to a full auth token. Anyone who obtains it has complete access to the Telegram account. The `.env` file is properly gitignored and `.env.example` has only placeholders. Noted for awareness.
- **Fix:** Document sensitivity prominently; consider encrypted session storage.
